Project · Poster design

Dead Poets Society Poster

GIMP · Python-Fu · Print design

A reimagined poster for Dead Poets Society, designed in GIMP. The composition uses layered typography and a restrained palette to echo the film's themes of tradition, rebellion, and poetic voice.

To make the layout reusable, I wrote a Python-Fu plug-in that rebuilds the poster grid from a folder of user images: it places the portrait, applies the title treatment, and exports a print-ready file. The result is both a finished poster and a small automation workflow.

Tools and process

  • GIMP for composition, typography, and colour adjustment
  • Python-Fu for automating image placement and text layers
  • A reusable layout system rather than a one-off poster file
