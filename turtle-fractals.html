Turtle Fractals Collection

Python · Turtle · Recursive drawing

A set of recursive drawing experiments made with Python's Turtle module. The collection includes branching trees and fern-like structures, built from simple recursive rules and varied angles, lengths, and colour parameters.

The project was an exercise in translating mathematical rules into visual form, and in tuning small parameter changes to produce very different organic patterns. Each piece is generated by code, but the variation in line weight, branching angle, and colour makes the output feel closer to a drawing than a diagram.

Tools and process

  • Python and the Turtle graphics library
  • Recursive functions with adjustable depth and branching angles
  • Parameter studies comparing natural and geometric forms
